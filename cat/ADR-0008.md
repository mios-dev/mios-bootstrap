## Summary of Decisions

1. **Canonical Ownership**: `cat/` in `mios-bootstrap` is the single source of truth for the installer payload.
2. **Unified Entry Point**: `MiOS-Cat.bat` (and its shims `.ps1` and `.sh`) is the canonical installer interface.
3. **Partition Model**:
   - `MiOS-Repo`: Small shadow-config partition (always present, holds SSOT `mios.toml`, launcher, architecture docs, and minimal code repos).
   - `MiOS-Data`: Bulk payload store created **only on disks ≥ 512 GB** (holds OCI tarballs, build artifacts, GGUF/AWQ model weights, and package mirrors).
4. **SSOT Integration**: All installer configuration parameters resolve from the `[cat]` block in `usr/share/mios/mios.toml`.
